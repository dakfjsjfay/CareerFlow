方法与合规说明
  • 只抽骨架和词表,句子自己重写。参考的是公开岗位的结构(职责 4–6 条、要求 3–5 条、加分项、待遇)和通用技能名词,没有复制任何岗位原文,也不是「换几个词」式的改写。
  • 虚构化到组合级别。公司名全部虚构,不与真实城市、薪资、人数形成可反查的组合;内部产品名、系统名一律不出现。
  • MOCK 覆盖所有视图。页面横幅、列表卡片、详情面板、导出文件名与导出数据(每条 isMock: true + meta.notice)都带标识,导出后仍不会变成「看起来像真招聘」的数据。
  • 上线前可跑自检。同目录 build.js 会检查 MOCK 字段、联系方式 / 外链 / 真实企业名、条数区间、重复句子,任一项不通过就不产出文件;本页页脚也做了一次运行时自检。
