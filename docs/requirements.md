> 版本：v1.0（2026-11-08）
> 状态：待导师架构审查
> 依据优先级：赛题原文 > 团队设计文档（E:\2 三份 + Chat 3）> Claude 优化建议

## 1. 赛题原文（最高优先级依据）

**赛题 3/C：自然语言对话式简历生成与精准投放**

- **核心痛点**：简历制作繁琐、难以精准匹配岗位
- **背景**：求职简历制作耗时，且投递缺乏针对性。本赛题要求开发一个对话式简历生成系统，通过自然语言交互收集信息、自动生成简历，并实现精准投放。

**功能需求（赛题明确要求）：**

| # | 赛题要求 |
|---|---|
| 1 | 提供对话式交互界面，通过多轮对话引导用户输入教育经历、工作/实习经历、技能、项目经验等 |
| 2 | 利用 NLP 或大模型技术解析用户输入，自动抽取并填充简历模板 |
| 3 | 支持生成结构化简历，可导出为 PDF/Word 格式 |
| 4 | 用户输入求职意向（岗位、地点、薪资等），系统从内置职位库**或**招聘平台 API 中匹配合适职位 |
| 5 | 提供「一键投递」**或**投递建议（含匹配度分析、投递话术），并记录投递状态 |

**业务闭环要求（核心）：**

系统必须形成「对话收集 → 信息抽取 → 简历生成 → 职位匹配 → 投递反馈」的闭环：

- 简历生成后，用户可基于职位要求**反向优化**简历内容
- 投递状态（已读、面试邀请等）**应主动提醒**
- 支持**用户反馈结果以优化匹配算法**
- **不允许只做静态简历生成**，必须体现求职全流程的闭环

## 2. 赛题要求 → 系统功能映射

| 赛题要求 | 系统实现 | 优先级 |
|---|---|---|
| 多轮对话收集四类经历 | AI 对话建档模块（chat） | P0 |
| 解析输入、抽取填充模板 | 信息抽取 + 证据链（profile/ai） | P0 |
| 结构化简历 + PDF/Word 导出 | 简历生成 + 版本管理 + 导出 | P0（两者都做） |
| 求职意向 + 内置职位库/API 匹配 | 求职意向字段 + 内置职位库（10~20 条模拟 JD） | P0 |
| 一键投递或投递建议（匹配度分析+话术）+记录状态 | 模拟一键投递 + 投递建议（含 AI 话术）+ 状态机 | P0 |

| 反馈优化匹配算法 | 反馈统计回流到岗位推荐排序 | P0（轻量） |

## 3. 赛题合规性审查结论

对照赛题原文，团队原始设计（Chat 1/2）存在 5 处偏差，已在设计中修正：

| # | 偏差 | 修正 |
|---|---|---|
| 1 | 投递话术缺失 | 新增 POST /api/match/advice，AI 基于匹配结果与已确认证据生成话术 |
| 2 | 主动提醒被标 P1 | 提为 P0：GET /api/applications/follow-ups + 仪表盘提醒（轻量实现，不引入定时框架） |
| 3 | Word 导出标「尽量」 | PDF、Word 均 P0 |
| 4 | 工作/实习经历无表 | 新增 profile_experience 表 + 对应 API |
| 5 | 反馈未回流匹配 | 岗位推荐排序参考历史反馈统计（如实声明为统计启发式） |

**合规选择及理由（答辩备查）：**

- **内置职位库**（赛题允许「内置职位库或招聘平台 API」二选一）：招聘平台 API 存在授权、反爬、合规风险，14 天周期内不可控；内置 10~20 条模拟 JD 可完全控制演示效果。
- **模拟一键投递**（赛题允许「一键投递或投递建议」二选一，本系统两者都做）：无真实平台授权，一键投递以模拟形式完成，投递记录真实落库；岗位提供外部链接跳转（job.external_url）。
- **投递建议**：包含匹配度分析 + AI 投递话术，满足赛题「含匹配度分析、投递话术」的完整要求。

## 4. 最终 MVP 功能范围

### P0（必须完成，13 项）

1. 用户注册/登录（Spring Security + JWT + BCrypt）
2. 对话式建档：多轮对话、历史保存、中断恢复
3. 信息抽取：教育经历、工作/实习经历、技能、项目经历 + 证据链（来源+确认状态）
4. 信息补全：缺失字段识别、主动追问
5. 档案完整度：6 维度计分 + 雷达图
6. 结构化简历生成 + 版本管理（旧版本永不覆盖）
7. 简历导出：PDF + Word
8. 求职意向：目标岗位、意向城市、期望薪资
9. 内置职位库：10~20 条模拟 JD + JD 解析
10. 岗位匹配：技能矩阵、加权评分、逐技能证据解释 + 岗位推荐
11. 反向优化：差距分析 → 追问 → 证据补充 → 重新生成 → 重新匹配
12. 投递：模拟一键投递 + 投递建议（匹配度分析 + AI 话术）+ 状态机 + 状态历史
13. 主动提醒：待跟进投递列表 + 登录后提醒

### P1（时间允许再做）

- 反馈分析图表页（投递漏斗、版本效果，ECharts 简版）
- @Scheduled 定时提醒（自动标记 NO_RESPONSE）
- 多简历模板、技能同义词匹配
- 投递话术独立保存（MVP 实时生成不落库）
- 教育经历拆表 profile_education（MVP 单条存 user_profile）

### P2（明确不做）

真实招聘平台 API、爬虫、多智能体、微服务、Redis、消息队列、复杂 RAG。
